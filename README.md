## How it works

`main.py` (Python 3.13, standard library only) copies the pre-rendered `entry.png` to `/output/entry.png`, verifying the PNG signature and that the IHDR declares 1024×1024 pixels. No network, no third-party packages — the image is rendered locally beforehand with Pillow and committed here.

Run it:

```sh
python3 main.py
```
